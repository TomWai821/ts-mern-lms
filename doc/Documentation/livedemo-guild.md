The following walkthrough highlights the platform's core business workflows and domain-specific features<br>
Administrative CRUD operations are available but intentionally omitted for brevity

<details>
<summary>1. Dashboard & Analytics</summary>

- Try:
    - Navigate through the dashboard sections
    - Hover over the pie charts to view detailed statistics and percentage distributions

- Highlights:
    - Aggregated library statistics
    - User, Book, Fines data analytics
    - Visual data representation through interactive charts
</details>


<details>
<summary>2. Borrow & Return Workflow</summary>

- Navigate: 
    - Manage

- Try:
    - Open the Book Management page
    - Borrow a book through Self Loan
    - Return a borrowed book
    - Observe how loan records and book status update automatically

- Highlights:
    - End-to-end borrowing workflow
    - Real-time inventory status updates
    - Automatic loan record generation
    - Return-book lifecycle management
</details>


<details>
<summary>3. Loan Book History & Filtering</summary>

- Navigate:
    - Profile Icon → Records

- Try:
    - View historical loan records
    - Apply Book Name / Status filters
    - Compare previous loan records with the recommendation section

- Highlights:
    - Dynamic filtering with real-time results
    - Personalised recommendations generated from historical borrowing behaviour
    - Recommendation results commonly share similar genres, languages, or borrowing patterns with previously loaned books
</details>


<details>
<summary>4. Book Recommendation & Book Modal</summary>

- Navigate:
    - Library

- Try:
    - Browse recommended books
    - Open any recommended book
    - Compare the recommended books with previous loan records

- Highlights:
    - Recommendation engine based on historical borrowing records
    - Google Books API integration
    - Rich book metadata display through a dedicated book details modal
</details>
