### Personal Recommendation
- The Personal Recommendation feature generates personalised book suggestions based on a user's borrowing history and book metadata

#### Recommendation Pipeline
- **Metadata Collection**
    - Retrieve the user's 10 most recent borrowing records
    - Collect candidate book metadata from the catalogue

- **Corpus Construction**
    - Build the user interest corpus from the recent borrowing records
    - Build candidate book corpora using book title, genre, author, and publisher

- **Candidate Scoring**
    - Score and rank candidate books using TF-IDF similarity and genre weighting
    - Select the top 20 candidates, then exclude books in the user's 10 most recent borrowing records
    - Return up to 8 remaining books

- **Recommendation Generation**
    - Select the highest-ranked books as recommendation candidates
    - Cache the generated results to reduce repeated computations

- **AI Explanation**
    - Submit the user's derived genre-preference profile and recommended-book metadata to DeepSeek
    - Generate contextual explanations describing why each recommended book aligns with the user's reading interests

## Recommendation Engine
- The recommendation engine uses a content-based filtering approach to measure the similarity between a user's reading interests and available books.

### Logic Explanation
- **TF-IDF Based Similarity Scoring**
    - Transforms user preferences and candidate books into metadata corpora
    - Applies TF-IDF vectorisation to quantify the importance of metadata terms
    - Generates feature vectors representing both user interests and book characteristics

- **Similarity Measurement**
    - Uses Cosine Similarity to measure the relevance between user and book vectors
    - Higher similarity scores indicate stronger alignment with the user's historical reading behaviour

- **Genre Preference Weighting**
    - Applies additional weighting based on genre frequency within the user's borrowing history.
    - Prioritises books from genres the user interacts with more frequently

- **Final Score**
    - Final Score = 0.7 × TF-IDF Similarity + 0.3 × Genre Preference Weight

### Remarks
- The recommendation engine is responsible exclusively for recommendation scoring and ranking
- Natural-language recommendation explanations are generated by a separate AI explanation layer after ranking has been completed
- Recommendation explanations do not influence recommendation scores or ranking results
